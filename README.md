# 던전 탈출 텍스트 RPG

C++ 학습을 목적으로 제작한 Windows 콘솔 기반 텍스트 RPG입니다.

캐릭터의 능력치를 생성하고 직업을 선택한 뒤, 전투와 아이템 획득을 거쳐
슬라임, 고블린, 오크, 드래곤이 등장하는 던전을 공략합니다.

게임 기능을 만드는 과정에서 배열, 포인터, 상속, 다형성, 템플릿,
동적 메모리, 깊은 복사, STL 자료구조 등을 직접 사용하고 학습했습니다.

> 현재도 기능과 코드 구조를 계속 개선하고 있는 학습 프로젝트입니다.

## 개발 환경

- C++
- Visual Studio 2022
- Windows Console
- Git / GitHub

`system("cls")`와 Windows 콘솔 API를 사용하므로 현재는 Windows 환경을 기준으로 실행됩니다.

## 게임 진행

```text
캐릭터 이름 입력
→ 랜덤 능력치 생성 및 리롤
→ 직업 선택
→ 메인 메뉴
→ 던전 입장
→ 일반 몬스터 3마리 처치
→ 보스 드래곤 처치
→ 게임 클리어
```

## 주요 기능

### 캐릭터 생성

- 캐릭터 닉네임 입력 및 변경
- HP, MP, 공격력, 방어력 생성
- 각 능력치를 50~100 사이의 무작위 값으로 설정
- 최대 3번까지 스탯 리롤
- `기존 능력치 → 새로운 능력치` 비교 출력
- 능력치 확정 후 재변경 제한
- 능력치와 직업을 모두 확정해야 게임 시작 가능

### 직업 시스템

`Player`를 부모 클래스로 사용하고 각 직업 클래스에서 공격과 스킬을
오버라이딩했습니다.

| 직업 | 전직 보너스 | 스킬 |
|---|---|---|
| 전사 | HP +20, 공격력 +10 | 공격력 1.2배, 1회 공격, MP 20 |
| 마법사 | MP +20, 공격력 +10 | 공격력 1.5배, 1회 공격, MP 25 |
| 도적 | HP +10, 공격력 +20 | 방어력 무시, 공격력 0.4배, 2회 공격, MP 20 |
| 궁수 | HP +10, MP +10, 공격력 +10 | 방어력 무시, 공격력 0.4배, 2회 공격, MP 20 |

직업을 확정하기 전에 직업 보너스와 스킬 설명을 확인할 수 있으며,
캐릭터 설정 단계에서는 직업을 다시 선택할 수 있습니다.

### 턴제 전투

전투 중 다음 행동을 선택할 수 있습니다.

1. 공격
2. 스킬
3. 방어
4. 인벤토리에서 포션 사용
5. 턴 넘기기

플레이어의 행동이 끝나면 몬스터의 턴이 진행됩니다.

- 공격력과 방어력을 이용한 데미지 계산
- 계산된 데미지가 0 이하라면 최소 데미지 1 적용
- 방어 시 받는 데미지 감소
- 직업별 스킬과 MP 소모
- HP 및 MP 포션 사용
- 행동 사이에 Enter 입력과 화면 초기화 적용

### 경험치와 레벨업

몬스터마다 서로 다른 경험치 보상을 가집니다.

```text
몬스터 처치
→ 경험치 획득
→ 최대 경험치 확인
→ 레벨 증가
→ HP +10, MP +5, 공격력 +5
→ 다음 레벨 최대 경험치 증가
```

플레이어 상태 화면에서 현재 레벨과 경험치를 확인할 수 있습니다.

### 템플릿 인벤토리

STL 컨테이너를 사용하는 것에서 더 나아가 템플릿과 동적 메모리를
이용한 `Inventory<T>` 클래스를 직접 구현했습니다.

```cpp
template<typename T>
class Inventory
{
private:
    T* pItems_;
    int capacity_;
    int size_;
};
```

구현한 기능:

- 아이템 추가
- 마지막 아이템 제거
- 전체 아이템 출력
- 현재 아이템 수와 용량 조회
- 공간 부족 시 기존 용량의 2배로 자동 확장
- 아이템 가격순 정렬
- `new[]`를 이용한 동적 배열 할당
- `delete[]`를 이용한 메모리 해제
- 깊은 복사 생성자
- 복사 대입 연산자와 자기 대입 검사

생성자, 소멸자, 복사 생성자, 복사 대입 연산자를 구현하면서
얕은 복사 문제와 Rule of Three를 학습했습니다.

### 포션 제작소

포션 제작소에서는 다음 기능을 사용할 수 있습니다.

- 전체 포션 레시피 출력
- 포션 이름으로 검색
- 재료 이름으로 검색
- 포션별 재고 확인
- 포션 지급
- 공병 반환

현재 등록된 레시피:

| 포션 | 재료 |
|---|---|
| HP 포션 | 허브 x1, 맑은 물 x1 |
| 스테미나 포션 | 허브 x1, 베리 x1 |

포션 재고는 `map<string, int>`로 관리합니다.

```text
포션 이름 → 재고 개수
```

- 레시피 등록 시 초기 재고 3개 설정
- 재고가 0이면 지급 실패
- 공병 반환 시 재고 1 증가
- 최대 재고 3개 제한

### 순차 던전과 보스전

일반 몬스터의 주소를 `vector<Monster*>`에 저장하고 순서대로 전투를 진행합니다.

```cpp
vector<Monster*> rooms = {
    &slime,
    &goblin,
    &ork
};
```

| 구역 | 몬스터 | HP | 공격력 | 방어력 |
|---|---|---:|---:|---:|
| 1번 방 | 슬라임 | 30 | 15 | 0 |
| 2번 방 | 고블린 | 50 | 25 | 0 |
| 3번 방 | 오크 | 80 | 35 | 0 |
| 보스방 | 드래곤 | 200 | 60 | 20 |

- 앞의 방을 클리어해야 다음 방으로 진행
- 일반 방 3개 클리어 시 보스방 자동 개방
- 플레이어 사망 시 `게임 오버!` 출력 후 종료
- 드래곤 처치 시 `게임 클리어!` 출력 후 종료

## 실행 방법

1. 저장소를 Clone하거나 내려받습니다.
2. Visual Studio 2022에서 `Project3.sln`을 엽니다.
3. 빌드 구성을 `Debug`, 플랫폼을 `x64`로 설정합니다.
4. `Ctrl + F5`를 눌러 실행합니다.

## 개발 과정에서 배운 점

처음에는 콘솔에서 실행되는 간단한 텍스트 RPG라고 생각했지만,
캐릭터 생성부터 전투, 직업, 인벤토리, 포션 제작소, 던전을 하나의 흐름으로
연결하려면 다양한 C++ 개념이 필요하다는 것을 알게 되었습니다.

특히 다음 내용을 구현하는 과정이 어려웠습니다.

- 포인터로 함수 밖의 원본 값을 변경하는 방법
- 부모 포인터로 서로 다른 자식 객체를 다루는 다형성
- 동적 메모리의 할당과 해제
- 얕은 복사를 방지하는 깊은 복사
- 함수 선언과 함수 정의의 차이
- 중괄호에 따른 함수와 반복문의 범위
- 여러 기능을 하나의 게임 흐름으로 통합하는 과정

컴파일 오류가 100개 이상 발생한 적도 있었지만, 앞부분의 중괄호나 함수 위치가
잘못되면서 발생한 연쇄 오류라는 것을 확인했습니다. 이후에는 오류 개수에
당황하기보다 컴파일러가 보여주는 첫 번째 오류부터 확인하는 습관을 익혔습니다.

- 포션 제작소 재고와 실제 전투 포션 연결
- 존재하지 않는 포션 이름 입력 시 예외 처리
- HP와 MP의 최대 수치 추가
- 인벤토리 정렬 메뉴 연결

- 던전 층과 보스 추가
- 스마트 포인터를 이용한 메모리 관리
- Windows 이외의 운영체제에서도 실행할 수 있도록 화면 처리 개선
